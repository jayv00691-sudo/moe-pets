# 萌宠角色图鉴

一个**纯静态单文件**网页。**默认只读浏览**，输入编辑密钥后才解锁编辑；改动保存在浏览器本地（localStorage / IndexedDB），刷新、关闭浏览器都不丢失。

## 🔒 编辑权限

页面默认就是**只读**的 —— 任何人拿到链接都只能看，改不了任何东西，也看不到编辑按钮。

**解锁方式**（任选其一）：

1. 打开 `https://<用户名>.github.io/moe-pets/?edit=你的密钥` —— 一次性解锁，之后这台设备直接打开就一直是编辑模式（密钥会自动从地址栏抹掉）
2. 点页面上的「🔒 编辑」按钮 → 输入密钥

解锁后顶部按钮变成「🔓 编辑中 · 锁定」，点它就退出编辑模式。

密钥本身**不在仓库里**。仓库里的 `config.js` 只有一串随机盐值和 SHA-256 哈希：

```js
window.MOE_EDIT = { salt: "…", hash: "…" };   // hash = sha256(salt + 密钥)
```

想换密钥：跑 `node scripts/_genkey.js`，它会重写 `config.js` 并打印新密钥，然后 push。换了之后所有设备会重新锁定，需要用新密钥再解锁一次。

## 在线预览（本地）

直接双击 `index.html` 即可，无需安装任何依赖、无需联网。
（用 `file://` 打开时读不到 `images/manifest.json`，相册是空的；要预览相册就 `npx serve .` 然后访问 localhost。）

## 部署到 GitHub Pages

### 方式一：从仓库分支发布（最简单）

1. 在 GitHub 新建一个仓库，例如 `moe-pets`（Public 才能免费使用 Pages）。
2. 把本目录下的文件推上去：

```bash
git init
git add .
git commit -m "feat: 萌宠角色图鉴"
git branch -M main
git remote add origin https://github.com/<你的用户名>/moe-pets.git
git push -u origin main
```

3. 打开仓库 → **Settings** → **Pages** → **Build and deployment**
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)`
   - 点 Save
4. 等 1–2 分钟，访问：`https://<你的用户名>.github.io/moe-pets/`

> 如果你不想把网页放在仓库根目录，可以把 `index.html` 放进 `docs/` 文件夹，然后 Pages 目录选 `/docs`。

### 方式二：GitHub Actions 发布

仓库里已附带 `.github/workflows/deploy-pages.yml`。推送后：
仓库 → **Settings** → **Pages** → Source 选 **GitHub Actions**，之后每次 push 到 `main` 都会自动部署。

## 图像库 📷

每只小动物都有自己的相册。**最省事的用法：照片直接扔进仓库。**

```
images/
├── tuantuan/    团团      ← 直接把照片丢进来
├── taotao/      桃桃
├── qiuqiu/      球球
├── daidai/      呆呆
├── tunuonuo/    兔糯糯
└── xiaoguai/    灰小乖
```

流程：`把照片丢进 images/<目录名>/` → `git push` → GitHub Action 自动重建 `images/manifest.json` 并部署 → 刷新网页，照片自动出现。

两种加照片的方式，随意混用：

**① 扔进仓库（推荐，能长期保存 & 多设备可见）**
把照片放进 `images/<目录名>/` 然后 push，Action 会自动重建清单并部署，刷新网页照片就出现。

**② 网页上直接上传**
鼠标移到头像上 → 右下角出现 📷 → 点一下选照片（支持多选）。第一张会自动成为头像。
上传的照片存在浏览器的 **IndexedDB** 里，刷新不丢，但只在这台电脑、这个浏览器上 — 要长期保存或多设备看，还是用方式 ①。

换头像：点开任意一张照片 → 底部「🌟 设为头像」。想换回手绘头像 / Emoji，点详情弹窗里头像左下角的 ✕。

其他细节：
- 目录名对应角色详情页里的「**图片目录名**」字段（默认英文 id，可改成中文，改了就把文件夹一并改名）
- 仓库来的照片带「仓库」角标，**不能在网页上删**（要删就去仓库删文件）；上传的和手动添加的可删
- 首页卡片显示最多 4 张缩略图，点缩略图放大看大图；没有照片时不显示缩略图条，不留占位
- 本地预览先跑一次 `node scripts/gen-manifest.mjs`；用 `file://` 直接打开读不到清单，建议 `npx serve .`

## 界面结构

**首页卡片**（概览，只放最亮眼的信息）
头像 · 代表 Emoji · 名字 · 物种·性别 · 自称 · 性格标签 · **照片缩略图** · 口头禅 / 叫声 / 专属 Emoji / 喜欢（摘要，最多 3 条）

**详情弹窗**（点卡片打开）
未解锁时字段是只读的（可以选中复制，但改不动），底部只有「关闭」；解锁后全部字段可编辑。
基本信息 + 形象 + 性格 + 口头禅与叫声 + 喜恶 + 特殊行为 + 外观形象 + 专属配饰 + 图像库

## 可编辑字段

| 分组 | 字段 |
| --- | --- |
| 基本信息 | 名字、自称、性别、物种 |
| 形象 | 代表 Emoji、卡片配色（8 种渐变）、**头像照片**（点头像上的 📷 上传） |
| 性格特征 | 多标签，一行一个 |
| 口头禅与叫声 | 口头禅、叫声、专属 Emoji / 招牌表情 |
| 喜恶 | 喜欢（一行一个）、讨厌（一行一个） |
| 特殊行为 | 多条目，一行一个 |
| 外观形象 | 毛色 / 体型 / 五官描述 |
| 专属配饰 | 项圈、发夹、小衣服等 |

## 功能

以下功能**都需要先解锁**才可见 / 可用：

- 点卡片任意位置（或右上角「详情 ✏️」）打开详情弹窗并编辑字段，标题和头像随输入实时预览
- 新增角色 / 删除角色
- 点头像上的 📷 上传照片、设为头像
- 导出 JSON 备份 / 导入 JSON 恢复
- 恢复默认六只
- 快捷键：`Esc` 关闭弹窗，`Ctrl/Cmd + S` 保存

**任何情况下都能用**：顶部搜索（按名字、物种、性格、口头禅、行为等全字段实时过滤）、点缩略图放大看大图。

## 数据说明（重要）

- 数据存放在**浏览器 localStorage**，键名 `moe_characters_v1`；网页上传的照片存在 **IndexedDB**，库名 `moe_pets_images`。
- 它们**不会**上传到 GitHub，也不会在不同设备 / 不同浏览器之间同步 —— 每个人打开看到的都是自己改过的那份。
- 换设备、换浏览器、或清了浏览器数据，请用顶部的 **导出 JSON / 导入 JSON** 迁移（导出的是资料，不含上传的照片本体）。
- 无痕模式（隐身窗口）下关闭窗口数据会被清除，请注意导出备份。

```
├── config.js                 # 编辑密钥的盐值 + 哈希（不含密钥本身）

├── images/                   # 照片库，一个子目录对应一只
│   ├── manifest.json         # 自动生成，别手改
│   ├── tuantuan/
│   ├── taotao/
│   └── …
├── scripts/
│   ├── gen-manifest.mjs      # 扫描 images/ 生成清单

└── .github/
    └── workflows/
        └── deploy-pages.yml  # 生成清单 + 部署到 Pages
```
